# 🎰 FakeNews Roulette

Un gioco interattivo e visivamente spettacolare per testare la tua capacità di distinguere le notizie vere dalle fake news!

## 🎮 Come Giocare

1. **Gira la Ruota**: Clicca sul pulsante "GIRA LA RUOTA" per iniziare
2. **Leggi la Notizia**: Una notizia apparirà sullo schermo
3. **Decidi**: La notizia è VERA o FALSA?
4. **Scopri**: Ricevi punti per le risposte corrette e scopri la spiegazione
5. **Ripeti**: Gioca 10 round e cerca di ottenere il punteggio più alto!

## ✨ Caratteristiche

- 🎨 **Grafica Spettacolare**: Animazioni fluide, effetti particellari, gradienti moderni
- 🎰 **Ruota della Fortuna Animata**: Effetto di rotazione realistico con colori vibranti
- 🌟 **Sistema di Streak**: Bonus punti per risposte consecutive corrette
- 📊 **Statistiche Dettagliate**: Traccia i tuoi progressi e il tuo punteggio massimo
- 📱 **Design Responsivo**: Giocabile su desktop, tablet e smartphone
- ⌨️ **Controlli Tastiera**: Usa spazio/invio per girare, V/1 per Vera, F/2 per Falsa

## 🚀 Come Avviare

Semplicemente apri il file `index.html` nel tuo browser preferito!

```bash
# Opzione 1: Apri direttamente il file
open index.html

# Opzione 2: Usa un server locale (opzionale)
npx serve .
# oppure
python -m http.server 8000
```

## 🎯 Sistema di Punteggio

| Difficoltà | Punti Base |
|------------|------------|
| ⭐ Facile | 100 punti |
| ⭐⭐ Media | 200 punti |
| ⭐⭐⭐ Difficile | 300 punti |

**Bonus Streak**: +50 punti extra per ogni risposta corretta consecutiva (max +250)
