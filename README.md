# 🎰 FakeNews Roulette

Un gioco interattivo per testare la tua capacità di distinguere le notizie vere da quelle false!

## 🎮 Come Giocare

1. **Apri il gioco**: Apri `index.html` nel tuo browser
2. **Leggi le notizie**: Ti verrà presentata una notizia con titolo e contenuto
3. **Decidi**: Clicca su "VERA" se pensi che la notizia sia vera, o "FALSA" se pensi sia falsa
4. **Guadagna punti**: Rispondi correttamente per guadagnare punti!

## 📊 Sistema di Punteggio

- **100 punti** per ogni risposta corretta
- **Bonus Streak**: +25 punti extra per ogni risposta corretta consecutiva
- **Timer**: Hai 30 secondi per rispondere a ogni domanda
- **10 domande** per partita

## ✨ Caratteristiche

- 🎨 Design moderno e responsive
- ⏱️ Timer per ogni domanda
- 🔥 Sistema di streak per bonus punti
- 📱 Funziona su desktop e mobile
- 🇮🇹 Completamente in italiano
- 📰 20+ notizie vere e false

## 🚀 Avvio Rapido

Semplicemente apri il file `index.html` in un browser web moderno (Chrome, Firefox, Safari, Edge).

```bash
# Su macOS
open index.html

# Su Linux
xdg-open index.html

# Su Windows
start index.html
```

L'obiettivo è educare i giocatori a riconoscere le fake news e sviluppare un pensiero critico nei confronti delle informazioni che incontrano online.
